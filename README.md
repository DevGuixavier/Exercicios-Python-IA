# Python 50 Exercícios — Inteligência Artificial

Resolução de 50 exercícios de Python para a disciplina de Inteligência Artificial.

## Conteúdo

- Exercícios 1-10: Fundamentos (variáveis, operadores, loops, condicionais)
- Exercícios 11-20: Listas, dicionários, strings, algoritmos básicos
- Exercícios 21-30: Algoritmos avançados, jogos interativos
- Exercícios 31-40: Ordenação, recursão, jogo da velha
- Exercícios 41-50: Conjuntos, primos, análise de dados
